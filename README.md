# ATI-Normandy — project website (draft v2, November 2026)

This is a static website in French and English with no server and no database. Its layout follows the ANR SpatialTreeP site (an R flexdashboard): a dark navbar with page tabs, a light-blue sidebar and white cards. It runs on any static host, such as GitHub Pages or Huma-Num GitLab Pages, where SpatialTreeP is hosted.

The site has five pages. Each one has its own address:

| Address | Page |
|---|---|
| `#le-projet` | Summary and research programme (two tabs), key facts, map of the study area |
| `#cartographie` | Interactive map of the eight TRI, with one button per area |
| `#equipe` | Map of the two laboratories and the list of members |
| `#publications` | Preprints and conference papers |
| `#partenaires` | Research teams, funding, contact |

`?lang=en` opens the site in English. `?carte=rouen#cartographie` opens it on the Rouen map.

## Files

| File | What it is |
|---|---|
| `index.html` | All the text of the site. French and English sit side by side. Edit the text here. |
| `404.html` | Sends the old ati-normandy.fr addresses (`/fr/...`, `/en/...`, `/carte/...`) to the matching page. |
| `assets/site.css` | Layout, colours and type |
| `assets/site.js` | Page tabs, language switch, menu, map buttons, team map |
| `assets/plate.js` | The map of Normandy on the project page (generated by `tools/`, do not edit by hand) |
| `assets/fonts/` | Inria Sans and Spectral, under the SIL Open Font License 1.1 (licence files included) |
| `tools/` | Scripts that rebuild `assets/plate.js` |

The page loads Leaflet 1.9.4 from cdn.jsdelivr.net for the team map. Map tiles come from the IGN Géoplateforme.

## Editing

- **Text.** Every bilingual piece of text appears twice, as `<span lang="fr">…</span><span lang="en">…</span>` (or `<p lang="fr">` and `<p lang="en">`). Change both versions.
- **Publications.** Copy one `<li>…</li>` line in the right card and edit it. Put the newest first.
- **Interactive maps.** The Cartographie page loads its maps from the `cartes/` folder of this site. There is one self-contained HTML file per map, made with Python (folium). To update a map, replace its file in `cartes/` and keep the same name. Each button names its file in `data-file`.
- **Team map.** The laboratory locations are in `assets/site.js`, under `var labs`.

## Publishing on GitHub Pages

1. Create a public repository and upload the contents of this folder (`index.html`, `404.html`, `.nojekyll`, `README.md` and the folders `assets`, `cartes` and `tools`). Upload the contents, not the folder itself.
2. Go to Settings → Pages → Deploy from a branch, then choose `main` and `/ (root)`.
3. After one or two minutes the site is at `https://<account>.github.io/ati-normandy-site/`.

The site lives in the project's own GitHub account. Keep that account's login details and its two-factor recovery codes with the project coordinator, so that the site stays reachable when team members leave.

If the repository is named `<account>.github.io`, the site is published at `https://<account>.github.io/`.

## Using the ati-normandy.fr address

The person who manages the domain's DNS points it at GitHub Pages:

1. Add a file called `CNAME` that contains `ati-normandy.fr`.
2. Set the custom domain under Settings → Pages.
3. Create the DNS records that GitHub lists.

A static site has no member login and no publication form. Publications are edited in `index.html`.
