# ATI-Normandy — project website

https://atinormandy.github.io/

This is a static website in French and English with no server and no database. Its layout follows the ANR SpatialTreeP site (an R flexdashboard): a dark navbar with page tabs, a light-blue sidebar and white cards. It is hosted on GitHub Pages in the project's own account (ATInormandy).

## Pages

| Address | Page |
|---|---|
| `#le-projet` | Project summary, key facts, map of the study area |
| `#programme` | Research programme: overview of the three phases |
| `#datum` | Research programme: open data used, with source, release and use |
| `#cartographie` | Research programme: iterative maps of the eight TRIs |
| `#presentations` | Research programme: slides that present the general logic of the research |
| `#equipe` | Map of the two laboratories and list of members |
| `#publications` | Preprints and conference papers |
| `#partenaires` | Research teams, funding, contact |

In the navbar, the "Research programme" drop-down holds Overview, Datum, Iterative maps and Presentations.

- `?lang=en` opens the site in English.
- `?carte=rouen#cartographie` opens it on the Rouen map.

## Files

| File | What it is |
|---|---|
| `index.html` | All the text of the site. French and English sit side by side. Edit the text here. |
| `404.html` | Sends the old ati-normandy.fr addresses (`/fr/...`, `/en/...`, `/carte/...`) to the matching page |
| `assets/site.css` | Layout, colours and type |
| `assets/site.js` | Page tabs, drop-down menu, language switch, map buttons, team map, slide viewer |
| `assets/plate.js` | The map of Normandy on the project page (generated by `tools/`, do not edit by hand) |
| `assets/fonts/` | Inria Sans and Spectral, under the SIL Open Font License 1.1 (licence files included) |
| `cartes/` | The interactive maps, one self-contained HTML file per map (Python, folium) |
| `presentations/` | Slide PDFs and their cover images |
| `tools/` | Scripts that rebuild `assets/plate.js` |

The page loads Leaflet 1.9.4 from cdn.jsdelivr.net for the team map. Map tiles come from the IGN Géoplateforme.

## Editing

- **Text.** Every bilingual piece of text appears twice, as `<span lang="fr">…</span><span lang="en">…</span>` (or `<p lang="fr">` and `<p lang="en">`). Change both versions.
- **Publications.** Copy one `<li>…</li>` line in the right card and edit it. Put the newest first.
- **Datum.** Each source is one `<tr>…</tr>` row in the table on the Datum page.
- **Interactive maps.** To update a map, replace its file in `cartes/` and keep the same name. Each button names its file in `data-file`.
- **Presentations.** Put the PDF and a small cover image (PNG, about 600 px wide) in `presentations/`, then copy one `<article class="talk">…</article>` block on the Presentations page and change the file names and text.
- **Team map.** The laboratory locations are in `assets/site.js`, under `var labs`.

GitHub's web editor is enough for all of this. Open the file, click the pencil icon, edit, and click Commit changes. The site updates one or two minutes later.

## Publishing

The repository `ATInormandy/atinormandy.github.io` is published by GitHub Pages from `main`, `/ (root)`. Keep the account's login details and its two-factor recovery codes with the project coordinator, so that the site stays reachable when team members leave.

To serve the site at ati-normandy.fr, the person who manages the domain's DNS points it at GitHub Pages:

1. Add a file called `CNAME` that contains `ati-normandy.fr`.
2. Set the custom domain under Settings → Pages.
3. Create the DNS records that GitHub lists.

A static site has no member login and no publication form.

## Home-page map

`assets/plate.js` draws Normandy in Lambert-93 from open data:

- commune and département boundaries from IGN ADMIN EXPRESS;
- TRI flood zones (DREAL Normandie / Géorisques, 2020) and TRI communes, taken from the overview map;
- motorways, national roads and main railway lines from IGN BD TOPO, via the Géoplateforme WFS in November 2026;
- the coastline from Natural Earth.

To rebuild it (you need Python with shapely and pyproj, and Node with the npm packages `world-atlas` and `topojson-client`):

```
node tools/topo2geo.js <folder with node_modules> build/ne_countries_near.geojson
python tools/extract_layers.py cartes/index.html build
python tools/fetch_bdtopo.py build
python tools/build_plate.py build
python tools/make_plate_js.py build assets/plate.js
```
